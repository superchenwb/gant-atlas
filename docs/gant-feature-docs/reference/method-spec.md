# 方法文档规范 (method-spec)

本规范定义 Hooks 和工具函数（utils）功能文档的内容边界、必须覆盖的维度和禁止事项。

---

## 适用范围

适用于以下路径下的方法：

- `packages/*/src/hooks/**/*.ts(x)` — 业务 Hooks
- `packages/*/src/utils/**/*.ts(x)` — 工具函数

不适用于：
- 页面级临时 Hooks（仅被单一页面内部使用且无独立文件的 Hook）
- procomponents 框架内部 Hooks

---

## 文档输出路径

```text
packages/<pkg>/src/hooks/<path>/useXxx.ts
-> packages/<pkg>/docs/hooks/<path>/useXxx.md

packages/<pkg>/src/utils/<path>/formatDate.ts
-> packages/<pkg>/docs/utils/<path>/formatDate.md
```

单个文件对应单个 `.md` 文档。如果一个文件导出多个方法，在同一文档中分节描述每个方法。

---

## 必须覆盖的内容

### 1. 文件概述

- 说明该文件的整体职责（一句话）
- 如果文件导出多个方法，说明这些方法的共同业务主题

### 2. 每个导出方法的描述

每个方法独立成节，按以下结构描述：

#### 2.1 功能描述

- 一句话说明该方法的核心作用
- 说明它解决了什么问题，或负责哪段业务逻辑

#### 2.2 参数

以表格列出所有入参：

| 字段 | 要求 |
|---|---|
| 参数名 | 和代码保持一致 |
| 类型 | 语义化描述（如"字符串"、"对象"、"布尔值"），避免直接写 TS 泛型语法 |
| 是否必填 | 是 / 否 |
| 说明 | 描述参数的用途，不描述内部处理方式 |

#### 2.3 返回值

以表格列出返回值的各字段：

| 字段 | 要求 |
|---|---|
| 字段名 | 和代码保持一致 |
| 类型 | 语义化描述 |
| 说明 | 描述该字段的含义和用途 |

如果返回值是单一值（非对象），直接描述类型和含义即可。

#### 2.4 核心功能说明

按功能点分条描述方法的行为，每个功能点单独说明：

- **功能点名称**：（如"数据查询"、"翻页管理"、"状态重置"）
- **行为描述**：该功能点做什么、何时触发、产生什么可观察的结果

重点描述：
- 方法主动做的事（发起请求、更新状态、触发回调等）
- 返回的函数/方法的职责（如返回的 `onSearch` 函数的作用）
- 依赖哪些参数变化会触发重新执行（非内部 dep 细节，而是从调用方角度可感知的）

#### 2.5 使用场景与适用条件

- 该方法适合在哪类页面或组件中使用
- 有无前提条件（如需配合某组件使用、需要在特定上下文中调用等）
- 与其他 Hooks / 方法配合使用时的依赖关系说明（功能层面，不写变量名）

---

## 禁止事项

1. **禁止写内部实现细节**：不描述内部使用了哪些 React API、zustand、immer 等
2. **禁止写 API 路径**：不在文档中写死具体的接口地址，除非该路径是作为参数传入的可配置项
3. **禁止写源码引用**：不写"详见 useRequest""参见 store.ts"
4. **禁止写算法细节**：不描述内部数据转换逻辑的具体算法，只描述输入输出的语义
5. **禁止摘要代替具体**：不能只写"管理搜索状态"，必须展开到具体行为
6. **禁止伪造**：无法确认的内容写 `[待确认]`，不要猜测

---

## 内容完整性检查

- [ ] 文件整体职责已说明
- [ ] 每个导出方法都有独立描述节
- [ ] 每个方法的入参表已完整列出（含类型、必填、说明）
- [ ] 每个方法的返回值已完整描述
- [ ] 核心功能已按功能点分条描述，不只有总览
- [ ] 使用场景和前提条件已说明
- [ ] 文档中无内部 API 路径、Hook 实现细节、Store 变量名等

---

## 特殊情况处理

### 数据查询类 Hook（useXxxSearch / useXxxFind 等）

除通用维度外，额外说明：
- 查询的触发方式（自动触发 / 手动触发）
- 查询参数的来源描述（来自搜索表单、路由参数、上层传入等，不写变量名）
- 返回数据的结构描述（列表、树形、分页等）
- 查询状态（加载中、错误等）的返回情况

### 数据编辑类 Hook（useXxxEdit / useXxxSave 等）

除通用维度外，额外说明：
- 支持的编辑操作类型（新增 / 修改 / 删除）
- 编辑提交的流程（触发 → 校验 → 请求 → 反馈）
- 成功/失败后的行为（刷新列表、关闭弹窗等）

### 工具函数（utils）

除通用维度外，说明：
- 输入的数据格式和约束
- 输出的数据格式
- 边界情况处理（空值、异常值等）
