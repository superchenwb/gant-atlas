# 脚本文档模板

> 使用说明：每个测试脚本 `.ts` 文件生成一个同名 `.md` 文档，替换 `{变量}` 为实际值。

---

# {scriptName} 测试脚本说明

## 概述

| 项目 | 值 |
|------|-----|
| 脚本文件 | `{page-slug}/{script-file}.ts` |
| 所属页面 | {pageName} |
| 命名空间 | {namespace} |
| 覆盖区域 | {功能区域：查询区/表格区/弹窗区/...} |
| 严重程度 | {severity} |
| 标签 | {tags} |

## 前置条件

| 条件 | 说明 |
|------|------|
| 登录态 | 需要有效的 storage-state 登录态 |
| 数据依赖 | {依赖的数据/模块，如"需要产品数据存在"} |
| 页面状态 | {页面初始状态要求，如"列表页初始状态"} |
| 环境要求 | {环境特殊要求} |

## 测试步骤

| # | 操作描述 | 预期结果 | 涉及字段/组件 | 备注 |
|---|---------|---------|-------------|------|
| 1 | {操作描述} | {预期结果} | {字段名/组件名} | {备注} |
| 2 | ... | ... | ... | ... |

## 稳定数据

> 脚本中使用的 candidates.json 数据。

| 数据类型 | code | name | 来源模块 |
|---------|------|------|---------|
| {类型} | {code} | {name} | {ibom/icost} |

## 注意事项

- {特殊处理逻辑说明}
- {已知限制}
- {环境差异说明}
- {写操作的安全策略}
