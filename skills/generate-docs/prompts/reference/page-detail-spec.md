# 详情页文档规格

## 一、适用范围

适用于详情页、带头部信息的 ContextMenu 页面、包含基本信息和多个子页签的页面。

## 二、文档目标

详情页文档只描述页面事实：

- 详情页概述
- 头部信息
- 头部按钮
- 基本信息页签
- 子页签
- 弹窗
- 接口链路
- 特殊限制

不写测试脚本、自动化契约或执行深度。

## 三、完整性要求

详情页不能只描述页签存在与否，必须把每一个具体功能点逐项写全。

至少包括：

1. 每个头部按钮
2. 每个基本信息字段
3. 每个子页签中的按钮
4. 每个子页签中的列、字段、行操作、单元格点击行为
5. 每个弹窗入口
6. 每个独立可见模块
7. 每个明显的联动、校验、状态切换、刷新行为

禁止只写：

- “头部支持编辑和发布”
- “子页签支持维护数据”
- “存在关联弹窗”

必须继续展开到具体功能项。

全局拆分规则同样适用于详情页：

- 只要某个区域同时存在按钮区和表格 / 主内容区，就必须分开描述。
- 复杂按钮允许单独成 `button-{name}.md`。
- 如果按钮点击后打开复杂弹窗，优先把按钮与弹窗合并写进同一个 `button-{name}.md`。
- 只有复用型或必须独立表达的弹窗才单独成 `popup-{name}.md`。
## 四、详情页必须覆盖的内容

### 4.1 页面概述

- 页面中文名
- 页面英文名或目录名
- 页面功能
- 所属模块
- 路由地址
- 是否包含左侧列表面板
- 默认进入页签
- 全页面功能索引

`main.md` 必须增加“全页面功能索引”章节，至少列出：

- 头部按钮
- 复杂头部按钮文档
- 基本信息页签
- 各子页签
- 各子页签中的主要按钮和主内容区
- 独立弹窗或复用型弹窗

### 4.2 页面结构

必须在 `main.md` 中输出详情页结构图，使用文本框图或等价的结构化示意。

结构图至少覆盖：

- 头部按钮
- 基本信息页签
- 子页签
- 复杂弹窗

补充要求：

- 必须体现头部区域、页签区域和内容区域的层级关系。
- 有左侧列表面板时，要体现左右分栏。
- 子页签内容区如果包含搜索区、按钮区、表格区等，应在结构图中标明主要区域。

### 4.3 头部展示信息

必须覆盖：

- 主标识
- 状态
- 类型
- 补充信息
- 描述项字段
- 左侧列表面板（如有）

### 4.4 头部按钮

必须覆盖：

- 按钮名称
- 显示条件
- 禁用条件
- 点击结果
- 二次确认
- 成功后结果

每一个头部按钮都必须单独描述。

如果头部按钮功能复杂：

- 允许单独成 `button-{name}.md`
- 主文档或 `header-buttons.md` 中保留入口和链接
- 如果头部按钮打开弹窗，且该功能复杂，按钮文档里要把弹窗内容一起写完整
- 头部按钮文档必须包含状态差异矩阵，至少覆盖权限状态、详情状态、审批状态中的关键差异

### 4.5 基本信息页签

必须覆盖：

- 字段标签
- 参数名
- 控件类型
- 回显规则
- 必填与只读/禁用
- 联动
- 校验
- 保存结果

每一个字段都必须单独描述。

### 4.6 子页签

必须覆盖：

- 页签名称
- 页面结构
- 按钮区
- 表格区
- 弹窗
- 查询或刷新逻辑

子页签内的每一个按钮、行操作、列点击、局部功能都必须单独描述。

如果子页签同时存在按钮区和表格区：

- 按钮主描述放在按钮文档
- 表格主描述放在表格文档
- 不能混写
- 子页签的按钮、表格、独立模块也要分别补充状态差异矩阵或等价清单

### 4.7 弹窗

必须覆盖：

- 标题
- 触发入口
- 打开条件
- 字段或子表格
- 联动
- 校验
- 提交结果

每一个弹窗入口都必须能在主文档或对应子文档中找到完整描述。

如果弹窗由某个按钮独占触发，且按钮功能复杂：

- 优先写进对应按钮功能文档
- 不强制再单独拆弹窗文档
## 五、接口归类规则

接口按详情页触发场景归类：

- 主详情加载
- 基本信息保存
- 头部按钮操作
- 子页签查询 / 保存
- 弹窗提交

## 六、拆分原则

满足以下任一情况时拆分：

1. 子页签内存在独立按钮区和表格区
2. 子页签逻辑复杂
3. 弹窗内容较大
4. 单个子页签内部包含多个独立可见区域

## 七、写作约束

1. 只写页面事实，不写实现细节说明。
2. 不保留源码路径、导入路径、组件名、Hook 名。
3. 无法确认的内容写 `[待确认]`。
4. 详情页状态、只读态、显示差异属于页面事实，需要写清。
5. 不允许只写概述而省略具体功能项。
## 八、对应模板

详情页通常使用：

- `templates/page-detail/main.md`
- `templates/page-detail/header-buttons.md`
- `templates/page-detail/base-info-tab.md`
- `templates/page-detail/sub-tab.md`

复杂弹窗补：

- `templates/common/popup.md`
