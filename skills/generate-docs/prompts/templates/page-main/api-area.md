---

## 二、场景分类说明

| 场景 | 说明 | 典型接口名模式 |
|------|------|---------------|
| 查询 | 加载列表/详情数据 | `find*`, `list*`, `query*`, `search*`, `get*` |
| 保存 | 新增/编辑/批量保存 | `save*`, `create*`, `update*`, `batchSave*` |
| 删除 | 删除单条/批量删除 | `delete*`, `remove*`, `del*` |
| 导出 | 导出 Excel/PDF 等 | `export*` |
| 导入 | 导入文件数据 | `import*` |
| 其他 | 应用规则、检查标准等 | 不符合上述模式 |
